Detailed Description

template<typename PF, bool AA>
class constixel::shapes::basic_round_rect< PF, AA >

Fluent API for drawing rounded rectangles, plain (round_rect) or antialiased (round_rect_aa).

Provides a chainable interface for drawing filled and stroked rounded rectangles.

Template Parameters
AADraw with antialiasing.
