Detailed Description

template<typename PF, bool AA>
class constixel::shapes::basic_circle< PF, AA >

Fluent API for drawing circles, plain (circle) or antialiased (circle_aa).

Provides a chainable interface for drawing filled and stroked circles.

Template Parameters
AADraw with antialiasing.
