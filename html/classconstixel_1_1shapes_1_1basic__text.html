Detailed Description

template<typename FONT, typename PF, bool KERNING, text_rotation ROTATION, bool AA, bool CENTERED>
class constixel::shapes::basic_text< FONT, PF, KERNING, ROTATION, AA, CENTERED >

Fluent API for drawing text: text_mono, text_aa, text_centered_mono and text_centered_aa.

Provides a chainable interface for drawing text using monospace or anti-aliased fonts.

Template Parameters
AAThe font is an anti-aliased font.
CENTEREDThe text is centered at its position.
