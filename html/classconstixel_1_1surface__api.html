Detailed Description

template<typename D, typename PF>
class constixel::surface_api< D, PF >

Drawing API of image and dynamic_image. Every call builds a surface from view() on the fly and forwards to it, so no pointer is stored in the image.

Template Parameters
DStorage class, provides view() and view() const.
PFPixel class of the format, see basic_surface.
