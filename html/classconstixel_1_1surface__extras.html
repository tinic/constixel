Detailed Description

template<typename D, typename PF>
class constixel::surface_extras< D, PF >

The drawing functions of surface, image and dynamic_image which are another drawing function in a different form: the param struct overloads, the NUL-terminated string overloads, the _mono, _aa and centered text names and the fluent shapes. They are written here once and call the functions of D.

Template Parameters
Dsurface, or the storage class.
PFPixel class of the format, see basic_surface.
