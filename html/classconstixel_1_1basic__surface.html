Detailed Description

template<typename PF, typename BYTE>
class constixel::basic_surface< PF, BYTE >

Non-owning view of a pixel buffer with the read-only operations. Use the aliases: const_surface for read-only pixels, surface for drawing.

Template Parameters
PFPixel class of the format: pixel_1bit, pixel_2bit<GRAYSCALE>, pixel_4bit<GRAYSCALE>, pixel_8bit<GRAYSCALE>, pixel_24bit<GRAYSCALE> or pixel_32bit<GRAYSCALE>. image<...>::pixel_type names it.
BYTEuint8_t or const uint8_t.

Convert a rectangle of the current instance in chunks, the same byte stream as convert(). Call it with the same cursor and rectangle until it returns 0. Example, a partial update over SPI:

std::array<uint8_t, 64> chunk;
constixel::convert_cursor cursor;
while (size_t n = image.convert_chunk<constixel::RGB565_8BIT_SERIAL>(chunk, cursor, {0, 0, 32, 16})) {
spi_write(chunk.data(), n);
}
