Detailed Description

template<typename PF, bool AA>
class constixel::shapes::basic_line< PF, AA >

Fluent API for drawing lines, plain (line) or antialiased (line_aa).

Provides a chainable interface for drawing stroked lines.

Template Parameters
AADraw with antialiasing. The stroke width is a float then.
